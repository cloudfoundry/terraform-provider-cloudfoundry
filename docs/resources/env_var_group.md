# cloudfoundry_env_var_group (Resource)

Manages a Cloud Foundry environment variable group. There are two environment variable groups: `running` and `staging`. These groups contain environment variables that are applied globally to all applications during the respective lifecycle phase.

__Further documentation:__
https://v3-apidocs.cloudfoundry.org/version/3.207.0/index.html#environment-variable-groups

## Schema

### Required

- `name` (String) The name of the environment variable group; must be either `running` or `staging`.

### Optional

- `variables` (Map of String) Key/value pairs of environment variables to set in the group. Setting a key that already exists updates its value. Removing a key from the map removes it from the group.

### Read-Only

- `updated_at` (String) The date and time when the resource was updated in [RFC3339](https://www.ietf.org/rfc/rfc3339.txt) format.
